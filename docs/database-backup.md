# 운영 DB 백업

현재 백업은 사이트에 연결된 ChatGPT 예약 작업으로 실행합니다. 앱 서버의 cron이나 GitHub Actions가 아닙니다. 이 저장소를 복제하는 것만으로 예약 작업이나 Google Drive 연결이 복원되지는 않습니다.

- 실행 시간: 매일 오전 4시, Asia/Seoul.
- 첫 예약: 2026-10-14 04:00 KST.
- 대상: 운영 D1의 운행 기록, 정비 기록, 차량 정보 및 정비 선택 항목.
- 저장 위치: 소유자가 지정한 Google 스프레드시트. 문서 접근 권한은 연결된 Google Drive 계정으로 관리합니다.
- 날짜별 탭: 운행기록 백업_YYYYMMDD, 정비기록 백업_YYYYMMDD, 정비항목 백업_YYYYMMDD.
- 차량 정보 탭: 차량모델, 차량번호, 누적 km를 최신 값으로 갱신합니다. 누적 km는 설정값과 운행·정비 계기판 값 중 가장 큰 값입니다.
- 첫 행은 백업시각(KST), 둘째 행은 백업상태와 건수, 셋째 행은 열 제목, 넷째 행부터 실제 기록입니다. 0건은 상태에 명시합니다.
- 기존 원본 탭과 이전 날짜의 백업은 보존합니다. 같은 날짜에 재실행하면 중복 탭 없이 그 날짜의 사본을 갱신합니다.
- DB 조회가 모두 완료된 후 저장하며, 저장값과 건수를 재조회해 확인합니다. 조회가 잘리거나 누락되면 완료로 보고하지 않습니다.
- 비밀번호, 세션 키, 인증 시도 기록, 중복 제출 키는 백업하지 않습니다.

예약은 등록·활성화되었으며, 최초 예약 실행의 성공 여부는 별도 실행 결과로 확인해야 합니다. 수동 백업의 저장·재조회는 확인했습니다.

실제 DB 데이터, 백업 파일, 인증 토큰, 비밀 환경변수는 공개 저장소에 넣지 않습니다. 예약 변경이나 복구는 Sites에 연결된 작업과 Google Drive 연결에서 진행합니다.
